Document Upload Guide

This section tells you how to upload documents correctly. Upload only documents in PDF. The maximum file size is 50 MB.

1. Rules for a correct document

Follow these rules when you upload a document:

  • Upload the correct document type for the slot.
  • The system can validate digital PDFs as well as scanned PDFs.
  • Make sure the text is clear and the page orientation is upright.
  • Make sure the correct financial year and the ULB name are visible on the document.
  • The following financial documents are not accepted: (i) Trial Balance instead of a Balance Sheet, (ii) Compilation Report, Significant Accounting Policies and Notes on Accounts, Audit Certificate, Audit-in-progress Letter, Cover Letter, Annual Report instead of Audit Reports.

2. Conditions that cause a rejection

The system will reject the document if:

  • You upload the wrong document type for the slot.
  • The image quality is too low. The text is not readable.
  • The scan is dark, blurred, or shows only part of the page.
  • The financial year or the ULB name is missing.
  • A page is rotated, cropped, or partly visible.
  • It is one of the invalid document types.

3. Scanned documents and CamScanner PDFs

Question: Will a scanned document or a CamScanner PDF cause a problem?

No. The system accepts digital PDFs. The system also accepts scanned PDFs. This includes PDFs from scanner apps, for example CamScanner.

In most cases, the system will process the scanned document with no problem. The system will flag the document only if:

  • The scan quality is very poor.
  • The text is not readable.
  • Pages are missing.

Do not avoid scanned PDFs. Make sure the scan is readable.

4. Procedure: a document is rejected

Question: The system rejects my document. What do I do?

  1. Go to the upload screen.
  2. Upload the flagged document again.
  3. If the system rejects the document again, and you believe the document is correct, select Send for manual review.
  4. Wait for the review. A reviewer will check the document and respond within 48 hours.
